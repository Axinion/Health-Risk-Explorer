# Personal Health Risk Explorer

**[GitHub repository](https://github.com/Axinion/Health-Risk-Explorer.git)**

Streamlit app for exploring **diabetes risk** using an **XGBoost** model trained on the **PIMA Indians Diabetes** dataset (8 features). Includes SHAP explainability, clinical badges, population percentiles, a what-if risk simulator, and a one-page **PDF** health report.

> **Disclaimer:** This is an **educational demo**. It is **not** medical advice, not clinically validated, and must not be used for diagnosis or treatment. Always consult a qualified healthcare professional.

## Features

- **Dual input modes:** interactive sliders (“Try a Sample”) or **CSV upload** with row selection
- **Risk score:** model probability of diabetes (class 1), shown as a gauge (0–100%) with Low / Moderate / High bands
- **Clinical badges:** per-feature Normal / Borderline / High bands (`utils/health_thresholds.py`)
- **SHAP:** probability-space waterfall chart (`model/explain.py`) and optional global mean-|SHAP| view
- **Population comparison:** percentiles vs. saved training features (`utils/population_stats.py`, `data/training_features.npy` after training)
- **Risk trajectory simulator:** adjust BMI, Glucose, Blood Pressure, Insulin vs. current row; side-by-side **Current** vs. **Simulated** gauges
- **PDF report:** downloadable summary including metrics, clinical status, notable percentiles (&gt;60th), AI explanation slot, and general recommendations (`utils/pdf_report.py`)
- **Dark Streamlit UI** with theme in `.streamlit/config.toml`

## Setup

```bash
git clone https://github.com/Axinion/Health-Risk-Explorer.git
cd Health-Risk-Explorer
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python model/train.py       # Downloads data if needed, trains model, writes .pkl + training_features.npy + feature_names.json
streamlit run app.py
```

Open the URL Streamlit prints (usually `http://localhost:8501`).

## Training notes

- Zeros in **Glucose**, **Blood Pressure**, **Skin Thickness**, **Insulin**, and **BMI** are treated as missing and imputed with column medians before the train/test split.
- **80/20** stratified split; **XGBoost** hyperparameters: `n_estimators=200`, `max_depth=4`, `learning_rate=0.05`.
- The **PDF** export uses **ReportLab**; the SHAP snapshot in the PDF uses **Plotly** + **Kaleido** for PNG rendering.

## Dependencies (high level)

Python 3.10+ recommended. Main packages: `streamlit`, `pandas`, `numpy`, `scikit-learn`, `xgboost`, `joblib`, `shap`, `plotly`, `scipy`, `requests`, `reportlab`, `kaleido`.
